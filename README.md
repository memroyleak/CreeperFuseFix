# CreeperFuseFix

A Fabric mod that restores `fuse.ogg`'s original pitch when igniting a creeper. Companion mod to the [Lomando Scream Over Explosives](https://modrinth.com/resourcepack/lomando-scream-over-explosives) resource pack. You should install this unless you want a horrible noise to harrass you every three seconds.

## Build
Clone repo, then run `.\gradlew build`. Yeah that's all the instructions you get.

## Install
Mod's on Modrinth. If you dislike that for some reason, put `creeper-fuse-fix-1.0.0.jar` from the Releases page in your mods directory.
